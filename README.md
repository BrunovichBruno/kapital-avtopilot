# Капитал на автопилоте

Бот для автоматической публикации финансовых статей в Telegram-канал «Капитал на автопилоте».

## Что делает

- Парсит 8 RSS-источников (РБК, ТАСС, Ведомости, Forbes, Банки.ру, Коммерсант, 1Prime)
- Достаёт статьи из Википедии (экономика, финансы, инвестиции)
- Делает рерайт через Gemini 3.6 Flash
- Публикует в Telegram с картинкой
- Добавляет опросы (до 3 в день)
- Защищён от дублей на 6 уровнях

## Стек

- Python 3.11
- google-genai
- feedparser, beautifulsoup4
- telegraph, requests
- GitHub Actions

## Расписание

Каждые 2 часа с 5:00 до 23:00 UTC (08:00–02:00 МСК).
